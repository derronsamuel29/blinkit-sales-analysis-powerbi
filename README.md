# 📊 Blinkit Sales & Business Analytics Dashboard

## 📌 Project Overview

This project focuses on analyzing Blinkit's sales data and building an interactive **Business Analytics Dashboard using Microsoft Excel and Power BI**.

The objective was to understand sales performance across different outlet types, outlet sizes, locations, product categories, and customer ratings.

---

## 🎯 Project Objectives

* Analyze overall sales performance
* Understand sales trends over time
* Compare different outlet types and sizes
* Analyze sales by outlet location
* Identify product category performance
* Analyze fat content across products
* Compare outlet-level performance
* Analyze customer ratings
